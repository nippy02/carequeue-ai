========================================
  CareQueue AI - How to Run
========================================

LOCATION:
The project is located at:
C:\Users\manue\carequeue-ai

TO OPEN IN FILE EXPLORER:
1. Press Windows Key + R
2. Type: C:\Users\manue\carequeue-ai
3. Press Enter

OR:
1. Open File Explorer
2. Navigate to: C:\Users\manue
3. Open the "carequeue-ai" folder

========================================
  QUICK START (EASIEST WAY)
========================================

METHOD 1: Using Batch Files (Easiest!)
---------------------------------------
1. Double-click "START_BACKEND.bat" (keep it open)
2. Double-click "START_FRONTEND.bat" (in a new window)
3. Wait for both to start
4. Browser will open automatically at http://localhost:3000

METHOD 2: Using Command Prompt
---------------------------------------
Open TWO Command Prompt windows:

WINDOW 1 (Backend):
  cd C:\Users\manue\carequeue-ai\backend
  npm install
  npm start

WINDOW 2 (Frontend):
  cd C:\Users\manue\carequeue-ai\frontend
  npm install
  npm run dev

Then open browser to: http://localhost:3000

========================================
  REQUIREMENTS
========================================

You need Node.js installed:
- Download from: https://nodejs.org/
- Install Node.js (includes npm)
- Restart computer after installation

To check if Node.js is installed:
  Open Command Prompt and type: node --version
  Should show: v16.x.x or higher

========================================
  TROUBLESHOOTING
========================================

If you can't see the folder:
- Make sure you're looking in: C:\Users\manue
- The folder name is: carequeue-ai
- Try refreshing File Explorer (F5)

If npm commands don't work:
- Install Node.js from https://nodejs.org/
- Restart your computer
- Try again

If ports are busy:
- Close other programs using port 3000 or 5000
- Or restart your computer
